- CCT is branded for **antiq** (antiq.xyz), a music technology company (antiq DAW free/AI, antiq forge plugin engine, antiq for artists, antiq stager). Dark Apple-minimal aesthetic, lowercase wordmark.
- **Why:** image models interpret the bare word "antiq" as *antiques* (furniture, vintage shops). The content-gen system prompt must forbid using "antiq" alone in image prompts and anchor visuals to the music universe (studios, synths, consoles, producers, waveforms).
- **How to apply:** any new prompt that feeds the brand name into an image generator must spell out the music-tech context, never the brand name alone.
- Legacy prediction-market features (thread-from-marketId, market slideshow, content-gen market context) still scrape opinionmarket.mx; they are labeled as an external legacy source — never brand that data as antiq's own product.
